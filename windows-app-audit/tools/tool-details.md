# Tool details

These descriptions explain the intended Photoshop function of every visible tool cataloged in the live audit. The descriptions are research-backed reference behavior; the live instance had no document, so canvas behavior remains UNTESTED.

## Marquee

- **Rectangular Marquee Tool** (M): Makes rectangular pixel selections.
- **Elliptical Marquee Tool** (M): Makes elliptical or circular pixel selections.
- **Single Row Marquee Tool** (): Makes a one-pixel-high selection across the image.
- **Single Column Marquee Tool** (): Makes a one-pixel-wide selection down the image.

## Move

- **Move Tool** (V): Moves a selection, layer, object, or guide.

## Lasso

- **Lasso Tool** (L): Draws a freehand selection boundary.
- **Polygonal Lasso Tool** (L): Builds a selection from straight-edged segments.
- **Magnetic Lasso Tool** (L): Builds a selection that snaps toward detected image edges.

## Selection

- **Quick Selection Tool** (W): Paints a selection while detecting nearby color and texture edges.
- **Magic Wand Tool** (W): Selects similarly colored pixels based on tolerance and contiguity.

## Crop

- **Crop Tool** (C): Trims the canvas or image to a chosen crop boundary.
- **Perspective Crop Tool** (C): Crops an image while correcting a perspective-shaped boundary.
- **Slice Tool** (C): Divides an image into rectangular slices for web-oriented output.
- **Slice Select Tool** (C): Selects and edits existing image slices.

## Sampling

- **Eyedropper Tool** (I): Samples a color from the image into the foreground color.
- **Color Sampler Tool** (I): Places sample points that report color values from the image.
- **Ruler Tool** (I): Measures distance, position, and angle in the image.
- **Note Tool** (I): Attaches an annotation note to an image.

## Healing

- **Spot Healing Brush Tool** (J): Removes small blemishes or objects by blending surrounding pixels.
- **Healing Brush Tool** (J): Repairs imperfections using sampled pixels while blending texture and tone.
- **Patch Tool** (J): Repairs a selected area using pixels from a sampled source or pattern.
- **Content-Aware Move Tool** (J): Moves a selected object and fills its former area using surrounding content.
- **Red Eye Tool** (J): Removes the red reflection caused by a camera flash.

## Clone

- **Clone Stamp Tool** (S): Paints a copy of pixels from a sampled source.
- **Pattern Stamp Tool** (S): Paints using a selected repeating pattern.

## History

- **History Brush Tool** (Y): Paints pixels from a chosen history state or snapshot.
- **Art History Brush Tool** (Y): Paints stylized strokes based on a chosen history state or snapshot.

## Eraser

- **Eraser Tool** (E): Erases pixels or restores them toward a saved state depending on its mode.
- **Background Eraser Tool** (E): Erases sampled background colors toward transparency as it is dragged.
- **Magic Eraser Tool** (E): Erases similarly colored contiguous pixels to transparency with a click.

## Fill

- **Gradient Tool** (G): Fills an area with a gradual blend between colors or presets.
- **Paint Bucket Tool** (G): Fills a contiguous similarly colored area with a color or pattern.

## Blur

- **Blur Tool** (R): Softens hard edges and reduces local detail.
- **Sharpen Tool** (R): Increases local edge contrast to make soft details appear sharper.
- **Smudge Tool** (R): Smears and blends pixels as though pushing wet paint.

## Tone

- **Dodge Tool** (O): Lightens selected image areas.
- **Burn Tool** (O): Darkens selected image areas.
- **Sponge Tool** (O): Raises or lowers color saturation in an area.

## Pen

- **Pen Tool** (P): Draws precise paths with straight and curved segments.
- **Freeform Pen Tool** (P): Draws paths freehand rather than point by point.
- **Add Anchor Point Tool** (P): Adds an anchor point to an existing path.
- **Delete Anchor Point Tool** (P): Removes an anchor point from an existing path.
- **Convert Point Tool** (P): Converts an anchor between corner and smooth curve behavior.

## Type

- **Horizontal Type Tool** (T): Creates editable horizontal point or paragraph text.
- **Vertical Type Tool** (T): Creates editable vertical point or paragraph text.
- **Horizontal Type Mask Tool** (T): Creates a selection shaped by horizontal text.
- **Vertical Type Mask Tool** (T): Creates a selection shaped by vertical text.

## Path Selection

- **Path Selection Tool** (A): Selects and moves an entire path or shape.
- **Direct Selection Tool** (A): Selects and edits individual path points or segments.

## Shape

- **Rectangle Tool** (U): Draws rectangular or square shapes and paths.
- **Rounded Rectangle Tool** (U): Draws rectangles with rounded corners.
- **Ellipse Tool** (U): Draws circular or elliptical shapes and paths.
- **Polygon Tool** (U): Draws polygonal shapes with a configurable number of sides.
- **Line Tool** (U): Draws straight line shapes or paths.
- **Custom Shape Tool** (U): Draws a selected predefined or custom vector shape.

## Navigation

- **Hand Tool** (H): Pans the image within its document window.
- **Rotate View Tool** (R): Rotates the canvas view without changing the image pixels.
- **Zoom Tool** (Z): Magnifies or reduces the document view.

## Mode controls

- **Quick Mask Mode**: Edits a temporary selection mask as an overlay.
- **Screen Mode**: Switches the Photoshop workspace display mode.
